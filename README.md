# ابزار تبدیل خودکار محتوای محصول برای مارکت‌پلیس‌ها

## مسئله
فروشگاه‌های آنلاین که در چند کانال فروش (دیجی‌کالا، باسلام، اسنپ و ...) فعالیت می‌کنن،
معمولاً محتوای هر محصول رو باید به‌صورت جداگانه و دستی برای هر پلتفرم بازنویسی کنن —
چون هر مارکت‌پلیس محدودیت طول عنوان/توضیحات، واحد قیمت (تومان/ریال)، و دسته‌بندی
متفاوتی داره. این کار برای صدها محصول، زمان‌بر و مستعد خطاست.

## راه‌حل
این اسکریپت پایتون یک فایل اکسل با فرمت داخلی فروشگاه رو می‌خونه و به‌صورت خودکار
برای هر مارکت‌پلیس هدف (در این نسخه: باسلام و دیجی‌کالا)، یک فایل CSV آماده آپلود
گروهی تولید می‌کنه — با رعایت:

- محدودیت طول عنوان و توضیحات (کوتاه‌سازی هوشمند در صورت نیاز)
- تبدیل واحد قیمت (تومان ↔ ریال)
- نگاشت دسته‌بندی داخلی به دسته‌بندی استاندارد هر پلتفرم
- تعیین وضعیت موجودی بر اساس موجودی انبار

## نحوه استفاده
```bash
python product_formatter.py --input sample_products.xlsx --marketplace basalam --output output_basalam.csv
python product_formatter.py --input sample_products.xlsx --marketplace digikala --output output_digikala.csv
```

## قابلیت توسعه
افزودن یک مارکت‌پلیس جدید فقط نیاز به اضافه کردن یک بلوک تنظیمات جدید در
دیکشنری `MARKETPLACE_RULES` داره — بدون نیاز به تغییر در منطق اصلی برنامه.

## فایل‌های این پروژه
- `product_formatter.py` — اسکریپت اصلی
- `sample_products.xlsx` — نمونه فایل ورودی
- `output_basalam.csv` / `output_digikala.csv` — نمونه خروجی تولیدشده
